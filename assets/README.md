# Assets Folder

Put your project images and screenshot assets here! 

The CSS is designed with high-quality animated fallback grids, so even if there are no images here initially, the website will render elegant background layouts.

## Recommended Image Dimensions
- **Technical Slides**: 800 x 600 px (Landscape)
- **Creative Slides**: 800 x 600 px (Landscape)
- **Project Cards**: 600 x 400 px
